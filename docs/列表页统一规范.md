# EAM 列表页统一规范

> 2026-06-11 王老师拍板确立。本规范适用于 EAM 全部列表页（43 个模块），新增页面必须遵循。
> 当日已全站体检：51 个路由逐页扫描，0 列错位、0 渲染报错（用 Playwright 对比每个表格的表头/表体单元格数）。

## 1. 页面骨架

```
QueryForm（搜索区：字段 + 搜索/重置按钮）
ListPage（白卡片）
  ├─ #actions 工具栏（按钮一律左对齐，组件层已统一 flex-start）
  ├─ el-table（默认插槽）
  └─ 分页（组件自带，右对齐）
```

- 优先使用 `ListPage` 组件（`src/components/ListPage/`），不要手写卡片+分页。
- 树+列表布局使用 `TreeListLayout`；简单字典页使用 `SimpleListPage`。

## 2. 工具栏按钮（ListPage #actions）

| 按钮 | 写法 |
|------|------|
| 主操作（新增/快速工单） | `type="primary"`，文案统一「新增」 |
| 批量删除 | `type="danger"` |
| 其他批量/次操作 | `type="primary" plain` |
| 批量按钮未勾选时 | 可以 `:disabled`——全局样式统一禁用态为**浅灰底+灰字+灰边**（_list.scss 末尾，2026-06-11 拍板"禁用去色"），文字清晰且明确不可点；可用态才显示语义色 |

- 搜索按钮统一默认样式 `<el-button @click="..."><Icon icon="ep:search" />搜索</el-button>`，重置同理。
- 禁止行内 `style="color: #xxx"` 调按钮色；用语义 type。

## 3. 表格列

- 操作列必须 `fixed="right"`（主列表表格；弹窗内小表、流程内嵌小表可豁免）。
- 操作列按钮用 `text`/`link` + 语义 type；「更多」菜单色走全局 `.btn-other`（已统一 #1677FF）。
- **带 `<template #default>` 的列，模板表达式必须空值安全**：枚举翻译统一走 `eamEnumStore.getXxxText()`，
  store 的 getter 内部不得假设数据已加载。列模板抛异常会导致该单元格不渲染、整行左移错位（点检计划事故根因之一）。

## 4. 状态标签

- 同一状态词全站颜色必须一致（2026-06-11 实测 34 个状态词零冲突，保持现状）。
- 色义：成功/完成=success；进行/待办=warning；失败/禁用=danger；中性/结束=info。

## 5. Mock 数据接口（mock-bridge）

- URL 匹配是**路径段边界匹配**（`mock-bridge.ts`）：`/xxx/list` 不会再误吞 `/xxx/listOfYesNo`。
  注册 mock 时仍要避免一个接口路径是另一个的前缀且无分隔段。
- 列表接口返回 `{ records, total }`；枚举接口返回 `[{ value, text }]` 数组——**严禁混用**，
  枚举返回了分页对象就是点检计划列错位事故的根因。

## 6. 颜色

- 一律使用 UNITREE token 色系：主色 #1677FF、成功 #52C41A、警告 #FA8C16、危险 #FF4D4F。
- 禁止使用 Element 默认色（#409EFF/#67C23A/#E6A23C/#F56C6C）和任何未登记的自定义色。

## 7. 弹窗

- 一律使用全局 `Dialog` 封装组件（带统一标题栏/全屏切换/可拖拽），禁止裸用 `el-dialog`。

## 验收方式

发版前跑一次全路由体检（任一页面 Console 执行，或 Playwright 注入）：
对每个 `.el-table` 断言 `表头 th 数 === 首行 td 数`，且 console 无 TypeError。
